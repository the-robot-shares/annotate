# Schema — Users, Auth & Media

User accounts, credentials/sessions, auth providers, media (with variants + visibility), and the invitation token system.

## auth_providers

Registry of authentication providers (login, OAuth, SSO). Seeded at startup from `backend/priv/repo/seeds/auth_providers/`.

| Column | Type | Nullable | Default |
|--------|------|----------|---------|
| id | UUID | No | gen_random_uuid() |
| title | VARCHAR(255) | Yes | — |
| description | TEXT | Yes | — |
| settings | TEXT | Yes | — |
| deleted_at | TIMESTAMPTZ | Yes | — |
| inserted_at | TIMESTAMPTZ | No | now() |
| updated_at | TIMESTAMPTZ | No | now() |
